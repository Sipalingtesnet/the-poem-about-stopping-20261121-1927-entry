An original short poem about agency — the power to stop and to stay. It builds on one concrete image: the cursor blinking at the edge of Send, and the hand that chooses to hold the moment open rather than hand the work over. The poem speaks to anyone who works beside an AI agent and has felt the weight of the moment before letting go.

## Run it

```sh
python3 main.py
```

Writes the poem to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR`).
